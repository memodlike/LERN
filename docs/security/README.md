# Security review

Проверка Codex Security завершена. [Неизменённый отчёт сервиса](baseline-report.md) относится к исходному commit `c9cd8f194b6101ad8955bf0cce18d549b574da9d`, а не к последней версии приложения. Идентификатор проверки: `b2c18977-ca03-4fed-a237-cfe3ad57b1a6`.

В исходной версии подтверждены две проблемы низкой серьёзности. Обе связаны с явно выбранными пользователем локальными файлами и доступностью приложения:

| Проблема исходной версии | Исправление |
|---|---|
| Недопустимые счётчики, курсоры и настройки в резервной копии могли приводить к сбою после восстановления | Проверка значений и связей до сохранения, безопасное восстановление оформления, тесты некорректных состояний |
| Некоторые форматы разворачивали слишком большой объём данных до проверки ограничений | Последовательная обработка TXT/CSV, предварительный бюджет структуры JSON, совокупные ограничения метаданных Markdown и регрессионные тесты |

Исправления включены в commits `07da795`, `abfbf1d`, `bcc0389` и `67ad647`. Статус находок в исходном отчёте сохранён: это снимок проверки исходной версии. Итоговая проверка исправленного приложения и точный проверенный commit указаны в [QA](../QA.md).

Область проверки: импорт и восстановление, локальная база, App Group, уведомления и ссылки на записи, WidgetKit/App Intents, обмен с Watch, экспорт изображений и локальные ресурсы. Покрытие частичное: выполнен анализ кода и целевые проверки, но не аудит поведения всех системных разрешений на физических устройствах. Отчёт не является гарантией отсутствия других уязвимостей.

В приложении нет серверной части, удалённых учётных записей, аналитики или сторонних библиотек времени выполнения. Файлы обрабатываются локально; системная отправка и резервная копия позволяют пользователю явно экспортировать свои данные.

Сервис вернул агрегированную статистику связанной работы четырёх задач: 20 616 975 токенов, включая 19 248 000 кешированных входных и 95 458 выходных. Это статистика сервиса за связанный контекст, а не стоимость проверки и не объём текущего сообщения.
