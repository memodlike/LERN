# QA evidence

Последнее состояние и точный commit проверяйте в [GitHub Actions](https://github.com/memodlike/LERN/actions/workflows/qa.yml). Этот файл будет дополнен результатом финального прогона.

## Выполненные проверки

- Подтверждены сборка iPhone и расширения WidgetKit, запуск iPhone Simulator и первоначальный UI-сценарий создания записи, избранного и выбора оформления.
- Отдельная сборка LERNWatch и его complication/Smart Stack прошла на Xcode 26.2.
- Проверка содержимого iPhone bundle подтвердила русский String Catalog, CAF-звуки, PrivacyInfo и Alternate Icons.
- Прогон на commit `abfbf1d`: 100 000 записей в дисковом SwiftData — 266,87 с; поиск одной записи — 0,238 с; парсер 50 000 записей — 3,04 с. Общий прогон был красным из-за отдельного теста CSV BOM + пробел, исправленного в `bcc0389`.
- Локальная проверка чистых парсеров через Command Line Tools: 50 000 записей — 2,43 с, CSV поля книг и отклонение чрезмерной вложенной структуры JSON прошли.

## Границы проверки

На локальном Mac установлен Xcode 26.6, но первоначальное принятие лицензии требует администратора. Command Line Tools не содержат SwiftDataMacros. Поэтому полноценные Xcode-проверки выполняются в GitHub Actions, а локально — синтаксис и отдельные чистые парсеры.

Физический iPhone и сопряжённые часы не использовались. Установка с подписью, работа App Group на реальном устройстве, фактическая доставка уведомления при Focus/блокировке, интерактивные виджеты на домашнем экране, двусторонняя WatchConnectivity, выбор фото из личной медиатеки и пользовательская автоматизация обоев требуют проверки после подписания. Проверка обработчика уведомления не означает подтверждение его показа системой.

Показатели времени относятся к конкретному Mac/CI runner, не к любому iPhone. Профили энергии, пиковой памяти импорта и VoiceOver на физическом устройстве ещё не сняты. YAML/YML импорт не реализован: в задании он указан как необязательный.
